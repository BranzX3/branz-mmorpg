# Onboarding and Player Journey

## First login

1. Acquire character session lease.
2. Validate required resource pack.
3. Create or load the single character.
4. Enter a safe introduction scene.
5. Choose presentation options, not class.

## Introduction sequence

The first hour teaches through play:

- move, interact and Chronicle slot 9;
- select/draw/sheathe a starter weapon;
- LMB chain, RMB defense/secondary, Shift dodge, F and Q;
- enemy telegraph, guard, posture break and conditional punish;
- Flask use and safe inventory risk;
- gather one node and process one material;
- city storage, market watch and an activity board;
- mount/stable introduction after the first road journey.

## Starter choice

The player chooses one starter weapon package among accessible families, but all mentors remain learnable. Choice grants equipment and tutorial path only, not permanent class identity.

## First regional arc

```text
city problem
→ road encounter
→ gather/craft preparation
→ mentor technique
→ party/LFG optional elite
→ field camp
→ first regional boss checkpoint
→ boss victory
→ market/trade/workshop unlock
```

The arc demonstrates that combat, lifeskill and city economy support each other.

## Failure protection

- Mercy Flask preparation.
- Basic repair and starter tools available at price ceilings.
- Quest rewards use Pending Rewards when inventory is full.
- Lost starter system items are reconstructed by definition/ownership reconciliation.
- No irreversible narrative choice locks core combat/lifeskill access.

## Returning player

Login summary may show pending rewards, sold orders, freight, completed worker jobs, expiring overflow and active contract status. It does not flood the player with compulsory daily chores.
