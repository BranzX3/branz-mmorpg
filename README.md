# Core MMO V1 Full Specification Pack

This package is the authoritative implementation baseline for a classless, action-combat MMO built on Minecraft Java / Paper 26.2.

Start with [`docs/00-README.md`](docs/00-README.md). Coding agents must read `02-system-invariants.md` before any subsystem document.

The pack covers the full V1 gameplay loop: combat, character progression, magic, items, quests, scenes, lifeskills, farming, workers, markets, regional trade, mounts, logistics, camps, navigation, party play, operations, release engineering and a designer-facing content authoring toolchain.


Content tooling is specified in [`docs/43-content-authoring-tools.md`](docs/43-content-authoring-tools.md): CLI/schema validation, in-game labs, deterministic traces, simulations, PR previews and immutable reports.
